# Ewoks: Forest Rescue

![Ewok from Ewoks: Forest Rescue](img/title/ewok.png)

Guide the Ewoks safely through the forest in this browser-based puzzle game. Choose the right skills, clear a path through each level, rescue the tribe, and collect Kybers for the leaderboard.

[Play Ewoks: Forest Rescue](https://www.stanleystuff.com/ewokgame)

## How to play

1. Select **Begin Rescue** and enter your scout name.
2. Choose a skill from the game toolbar.
3. Select an Ewok to assign that skill.
4. Rescue as many Ewoks as possible before time runs out.

Your progress is saved between visits. Completing levels earns Kybers and records your results on the leaderboard. If you have a Wicket available, you can use it to move past a difficult level without earning Kybers for that level.

## Game options

Before starting a rescue, open **Options** to choose:

- Game speed
- Episode
- Difficulty

## Project structure

- `index.html` — title screen and game interface
- `leaderboard.html` — player rankings
- `js/` — game engine and player progress
- `css/` — game and leaderboard styles
- `img/` and `audio/` — artwork and sound
- `api/` and `neon/` — leaderboard API and database migrations
